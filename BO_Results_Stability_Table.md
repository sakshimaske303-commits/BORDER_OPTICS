# BORDER OPTICS — Results Stability Table

*Drafted 2026-09-17, at Anara AI's suggestion in its review of this project: "a table, one row per estimate... columns for pre-fix value, post-fix value, what changed and why, final value... converts your history of reversals from an excavation exercise across the Development Log into a 10-second visual argument." Every number below is copied from `BO_Research_Paper.md` or `BO_Development_Log.md` as already written and frozen — nothing here is new analysis, and no number has been recomputed for this table. This is a draft for Sakshi to review and decide whether/where to fold into the paper (e.g. as a new §4.12 or an appendix); it has not been inserted into `BO_Research_Paper.md` itself, to respect `ANALYSIS_FREEZE.md`'s scope boundary.*

Five results in this study changed value between an earlier extraction/analysis and the current, frozen one. Each reversal was caught by this project's own completeness checks or by external review, diagnosed to a specific, named cause, and resolved by a full re-run — not patched over. This table lists all five in one place. No result in this study reversed a second time after its fix.

## What stayed stable throughout

For contrast: H3's night-lights-proximity result crossed the same window-dependent line in every version of this paper, unchanged by any of the five fixes above — significant full-year (p < 0.0001), null summer-matched (p = 0.266). It's included here to show the reversals above were specific, diagnosed data or code defects, not a pipeline that reshuffles every number on every run.
